
# Computer Networks Laboratory

This repository contains the practical experiments performed as part of the Computer Networks Laboratory. It covers fundamental networking concepts, network configuration, communication protocols, routing techniques, network simulation tools, and client-server applications.

The experiments are implemented using Cisco Packet Tracer, Python, command-line networking utilities, and other networking tools.

- **Domain:** Computer Networks
- **Tools Used:** Cisco Packet Tracer, Python, Wireshark, NS-3, OMNeT++, GNS3, Mininet and pfSense.

## Software and Technologies Used

### 1. Cisco Packet Tracer
Cisco Packet Tracer is a network simulation tool used to design, configure, and troubleshoot virtual network topologies. It allows users to simulate routers, switches, servers, and end devices.

### 2. Python
Python is used for implementing socket programming and client-server communication using TCP and UDP protocols.

### 3. Wireshark
Wireshark is a network protocol analyzer used to capture and inspect packets transmitted over a network.

### 4. NS-3 and OMNeT++
These are network simulation frameworks used to study network behavior, communication protocols, and traffic flow.

### 5. GNS3 and pfSense
GNS3 is used for network emulation, while pfSense provides firewall, routing, NAT, and network security functionalities.

## Learning Objectives

Through these experiments, the following concepts are studied:

- Understanding different types of network cables and transmission media.
- Identifying networking devices and their functions.
- Understanding IPv4 addressing and subnetting.
- Establishing communication between computers in a LAN.
- Configuring routers and switches.
- Understanding routing protocols and packet forwarding.
- Implementing Network Address Translation.
- Understanding TCP and UDP communication.
- Developing client-server applications using Python sockets.
- Configuring DHCP services for automatic IP allocation.
- Analysing network traffic and studying network simulation tools.
